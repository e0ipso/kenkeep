# Document the sweep, write-time placement, and the delete rule

## Objective

Correct every place that still describes the `nodes/` root as where homeless leaves live, teach the
curator that leaving `home_folder` empty now derives a folder, and document the sweep command.

## Skills Required

Technical writing and Markdown. One build command, no application code.

## Acceptance Criteria

- [ ] `src/templates-source/skills/kk-curate/SKILL.md.hbs`: the "Root fallback" item under "Relate
      and place" no longer promises that a later rebalance pass relocates the leaf, and states that
      the writer derives a folder from the candidate's own edges and tags when `home_folder` is
      empty.
- [ ] The same file's Step 7 placement reporting instruction tells the curator to distinguish a
      curator-chosen folder from a derived one, matching the `placement` values Task 2 emits.
- [ ] The `<!-- Version: N -->` comment in that file is bumped by one.
- [ ] `npm run build:templates` regenerates `templates/skills/kk-curate/SKILL.md` and
      `git diff --stat templates/` shows only that file changed.
- [ ] `src/lib/rebalance.ts`: the `ROOT_HOMELESS_EDGE_MAX` doc comment and the module header no
      longer describe the root as the place homeless leaves live. The code is unchanged.
- [ ] `src/commands/curate-persist.ts`: the `runCuratePersistCommand` doc comment describes
      derivation rather than the empty-`home_folder` root fallback.
- [ ] `AGENTS.md`: `node sweep` appears in the primitives list that currently names `node write`,
      `curate-dedup`, `index rebuild`, and the rest.
- [ ] `docs/internals/architecture.md`: `node sweep` appears in its primitives list.
- [ ] `README.md` documents the sweep where it describes the command surface. README has no literal

      required `init --upgrade` for repositories carrying an older installed `kk-curate` skill.
- [ ] `npm run format:check` and `npm run lint` exit 0.

`src/templates-source/skills/kk-curate/SKILL.md.hbs`, line 189 today:

> 4. **Root fallback.** If no existing folder clears your relevance bar, leave `home_folder`

Both halves change. Leaving `home_folder` empty is still correct when no folder clears the bar, but
the writer now derives a folder from the candidate's `kk_relates_to`, `kk_depends_on`, and tags. The
root is reached only when that derivation finds nothing, and no rebalance pass relocates it. Keep
the closing instruction: never force a weak fit just to avoid the root. It is still right, and it
matters more now that a weak explicit fit would override a better derived one.
